# 🤖 RescueFusion AI

The **AI** folder contains the computer-vision and artificial-intelligence components of RescueFusion.

### AI Components

* 👤 Survivor/person detection
* 🔥 Hazard detection
* 📷 RGB image processing
* 🌡️ Thermal perception
* 🎯 Detection and localization data
* ⚡ Edge AI inference
* 📊 Detection output and logging

The AI pipeline is designed for efficient onboard inference and integration with the drone's navigation and rescue-priority systems.

**Model:** YOLO-based detection
**Target Edge Platform:** Raspberry Pi 5 + Hailo-8
**Status:** 🚧 Under Development
