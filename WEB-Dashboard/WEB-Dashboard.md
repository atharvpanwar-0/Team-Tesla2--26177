# 🖥️ RescueFusion Web Dashboard

The **Web Dashboard** provides a command-center interface for monitoring and interacting with the RescueFusion mission.

### Features

* 🚁 Drone position and mission status
* 👤 Survivor detection information
* ⚠️ Hazard alerts
* 🗺️ Search area and mapping data
* 📊 Detection and mission logs
* 📡 Real-time mission information

The dashboard is designed to give rescue teams a clear overview of the drone's mission and detected events.
