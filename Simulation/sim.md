# 🧪 RescueFusion Simulation

The **Simulation** folder contains the Webots-based simulation environment used to develop and test the RescueFusion autonomous drone system.

### Simulation Includes

* 🚁 Drone movement and control
* 🧭 Navigation and coordinates
* 🗺️ Mapping
* 🧱 Obstacle avoidance
* 🛣️ A* path planning
* 📷 Camera-based perception
* 📝 Detection and mission logging

Simulation allows the autonomy system to be tested safely before physical drone deployment.

**Platform:** Webots
**Status:** 🚧 Under Development
